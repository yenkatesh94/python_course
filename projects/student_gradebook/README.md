# Student Gradebook

A beginner-friendly command-line project for recording student names and
scores. It practices input/output, loops, conditionals, functions, lists,
dictionaries, validation, exceptions, and JSON file handling.

## Run the project

From this folder, run:

```powershell
python main.py
```

Choose an option from the menu to add, show, or remove students. The gradebook
is saved in `students.json` in this folder when you add or remove a student.

Scores must be between 0 and 100, and duplicate student names are not allowed.

## Run the tests

```powershell
python -m unittest
```
